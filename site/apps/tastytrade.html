Does tastytrade work with ChatGPT, Claude and Grok?

tastytrade publishes an official MCP server, but you run it yourself on your own computer. It is not a one-click connector.

Checked Oct 31, 2026 · Brokerage · Route: Official open-source MCP (self-hosted)

Read-only or can it trade?

Can trade The server can place orders. tastytrade's docs describe a dry-run option for testing.

Known issues and caveats

  • Developer-style setup (install, API credentials).
  • No hosted consumer connector documented.

Common questions

Does tastytrade work with ChatGPT?

Unknown. tastytrade's pages do not list ChatGPT. A locally-run (stdio) server generally can't be added to ChatGPT's web app without extra hosting.

Does tastytrade work with Claude?

Partly. Self-hosted local server; works with MCP clients that can run local servers (for example Claude Desktop/Code). tastytrade's pages don't name Claude specifically.

Does tastytrade work with Grok?

Unknown. Not listed on tastytrade's pages.

Can an AI trade or move money in tastytrade?

AI can place real orders. The server can place orders. tastytrade's docs describe a dry-run option for testing.
