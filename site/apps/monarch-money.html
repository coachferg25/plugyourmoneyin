Does Monarch Money work with ChatGPT, Claude and Grok?

Monarch has an official MCP connector for ChatGPT and Claude. Read access by default, with optional write access.

Checked Oct 31, 2026 · Budgeting app · Route: Official MCP connector

AssistantStatusHow
ChatGPTWorksOfficial connector; Monarch's help page says ChatGPT web, on plans that support custom connectors.
ClaudeWorksOfficial connector listed on Monarch's help page.
GrokPartialNot listed as supported by Monarch. Remote MCP clients may accept the same URL, but this is not officially supported. inferred

Read-only or can it trade?

Read + edit Reads by default. Monarch describes an optional setting that lets the AI make changes in your Monarch data.

Known issues and caveats

  • Accounts connected through Finicity are excluded from the MCP, which affects some Fidelity and other investment accounts.
  • Keep write access off unless you need it.

Common questions

Does Monarch Money work with ChatGPT?

Yes. Official connector; Monarch's help page says ChatGPT web, on plans that support custom connectors.

Does Monarch Money work with Claude?

Yes. Official connector listed on Monarch's help page.

Does Monarch Money work with Grok?

Partly. Not listed as supported by Monarch. Remote MCP clients may accept the same URL, but this is not officially supported.

Can an AI trade or move money in Monarch Money?

Can read, and may be able to change data inside the app (not move money). Reads by default. Monarch describes an optional setting that lets the AI make changes in your Monarch data.
