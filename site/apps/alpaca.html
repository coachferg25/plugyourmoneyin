Does Alpaca work with ChatGPT, Claude and Grok?

Alpaca's official MCP server runs locally with your API keys. Defaults to paper trading.

Checked Oct 31, 2026 · Brokerage (API-first) · Route: Official open-source MCP (self-hosted)

AssistantStatusHow
ChatGPTPartialDocs mention ChatGPT only as 'see the README'; no hosted connector documented. inferred
ClaudePartialClaude Desktop and Claude Code are listed supported clients, but the server is self-hosted with your own API keys (developer-style setup).
GrokUnknownNot listed in Alpaca's supported-client table. no docs found

Read-only or can it trade?

Can trade 65 tools including placing orders, closing all positions and cancelling orders. Paper trading is the default; live trading needs ALPACA_PAPER_TRADE=false.

Known issues and caveats

  • You paste API keys into a local config, never into chat.
  • Toolsets can be limited (for example account + market data only) to make it read-only.

Common questions

Does Alpaca work with ChatGPT?

Partly. Docs mention ChatGPT only as 'see the README'; no hosted connector documented.

Does Alpaca work with Claude?

Partly. Claude Desktop and Claude Code are listed supported clients, but the server is self-hosted with your own API keys (developer-style setup).

Does Alpaca work with Grok?

Unknown. Not listed in Alpaca's supported-client table.

Can an AI trade or move money in Alpaca?

AI can place real orders. 65 tools including placing orders, closing all positions and cancelling orders. Paper trading is the default; live trading needs ALPACA_PAPER_TRADE=false.
